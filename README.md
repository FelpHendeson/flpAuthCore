# authCore
Authentication and user management API.

## Project Purpose
Study and portfolio project focused on authentication and user management, designed to be reusable as a future microservice.

## Quick Setup
1. `npm.cmd ci`
2. `npm.cmd run prisma:generate`
3. `npm.cmd run build`
4. `npm.cmd run dev`
